# Настройка gsc-api — инструкция для ИИ-агента

Этот файл читает не пользователь, а агент (Claude Code и т.п.), который
запускает скилл `gsc-api` и видит, что он ещё не настроен на этой машине —
обычно это ошибка про `GSC_CONFIG_DIR` при запуске `gsc.py`. Проведи
пользователя по шагам ниже. Часть шагов (вход в Google-аккаунт, согласие на
доступ) требует браузера и не может быть выполнена агентом за пользователя —
не пытайся автоматизировать эти шаги, а проси пользователя выполнить их и
подтвердить.

## 1. Зависимости

```
pip install -r requirements.txt
```

## 2. Папка для credentials

Скиллу нужна одна переменная — `GSC_CONFIG_DIR`: путь к папке, где будут
лежать `client_secret.json` и `token.json`. Спроси пользователя:

- Есть ли уже такая папка (например, общая для нескольких GSC-скиллов/проектов
  на этой машине)? Если да — используй её путь.
- Если нет — предложи создать новую папку, например `config/` рядом с `gsc.py`,
  или любое другое место по выбору пользователя.

## 3. OAuth-клиент в Google Cloud Console

Нужен, только если у пользователя ещё нет `client_secret.json`. Пользователь
делает это сам в браузере, ты — проводишь по шагам:

1. https://console.cloud.google.com/ → выбрать проект или создать новый.
2. APIs & Services → Library → найти **Google Search Console API** → Enable.
3. Если в проекте ещё не настроен OAuth consent screen — APIs & Services →
   OAuth consent screen → User type **External** → указать название приложения
   и email. Публиковать приложение не нужно, режима "Testing" достаточно
   (пользователь добавляет свой же email в тестовые пользователи).
4. APIs & Services → Credentials → Create Credentials → OAuth client ID →
   Application type **Desktop app**.
5. Скачать JSON → сохранить как `client_secret.json` в папку из шага 2.

## 4. Заполнить .env

В папке скилла скопировать `.env.example` в `.env` и вписать путь из шага 2:

```
GSC_CONFIG_DIR=<путь к папке с credentials>
```

`.env` в `.gitignore` — это локальный файл, в публичный репозиторий не попадёт.

## 5. Авторизация

```
python gsc.py auth
```

Откроется браузер — пользователь логинится под Google-аккаунтом, у которого
есть доступ к нужным property в Search Console, и подтверждает доступ
(`webmasters.readonly`, только чтение). Токен сохранится в
`GSC_CONFIG_DIR/token.json`.

## 6. Проверка

```
python gsc.py sites
```

Должен вывести список доступных property. Пустой список значит, что у
авторизованного аккаунта нет доступа ни к одному property — это добавляется в
самом Search Console (Settings → Users and permissions), скилл тут ничем не
поможет.
