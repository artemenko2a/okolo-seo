# gsc-api skill

## Это пишет человек, а не бездушная машина, поэтому прочтите.

Это скилл для ИИ-агентов, который их учит работать с Google Search Console API.

Фича в том, что скрипт скилла gsc.py содержит все необходимые методы для получения сырых данных, которые затем агент может анализировать. Все возможности скрипта описаны в [SKILL.md](SKILL.md), тем самым я минимизирую работу агента по получению данных (читать экономлю токены). Ему не нужно писать скрипт под каждый ваш уникальный запрос.

## Что он умеет 
Данные по конкретному URL, срез по стране/устройству/запросу,
сравнение двух периодов для поиска упавших или выросших страниц/запросов,
поиск каннибализации запросов, числовые фильтры по метрикам (точки роста),
статус индексации URL.

Рассчитан на нестандартные аналитические вопросы, на которые не отвечает
готовый отчёт в интерфейсе Search Console - без ручной выгрузки и постобработки
данных в Excel/Sheets каждый раз заново. Результаты кэшируются на диске, чтобы
повторные вопросы не тратили лимиты.

В скилл не заложена логика "что хорошо, а что плохо". Он просто получает данные затрачивая на это минимум токенов.

## Установка

При первом запуске скилла агент увидит, что токена GSC нет и пойдет в [SETUP.md](SETUP.md), где ему сказано помочь вам этот самый токен получить и положить где-то в папку, на которую указать указать путь в переменной `GSC_CONFIG_DIR` файла `.env`

Нужен OAuth-доступ к Search Console API (Google Cloud Console). Пошаговая
настройка — в [SETUP.md](SETUP.md).
