# yandex-wm-api skill

Скилл для ИИ-агентов, который учит их работать с API Яндекс Вебмастера.

Как и [gsc-api](../gsc-api), он не строит готовый отчёт, а даёт агенту весь инструментарий.
Скрипт `ywm.py` умеет получать сырые данные из всех разделов API, а [SKILL.md](SKILL.md)
объясняет агенту, где какие данные лежат и какие у них ограничения. Агенту не нужно
писать скрипт под каждый вопрос, а значит, меньше токенов и меньше ошибок.

## Что он умеет

- итоги сайта по дням, неделям, месяцам с 2020 года: показы, клики, CTR, позиции;
- запросы и страницы за последние 14 дней со спросом, фильтрами по тексту, адресу,
  региону и устройству; запросы одной страницы и страницы одного запроса;
- матрицу «запрос × страница» и поиск каннибализации;
- топ запросов и динамику запроса за прошлые недели;
- PRO-выгрузку «запрос × страница × регион» за 550 дней с подсчётом расхода лимита;
- все известные Яндексу страницы с кодом ответа, статусом в поиске и canonical;
  выпавшие страницы с причинами; историю индекса, обхода, ИКС и ссылок;
- диагностику, важные страницы, sitemap, внешние и битые ссылки;
- переобход страниц и sitemap (с сухим прогоном по умолчанию);
- любой другой метод API через `raw`, со справочником в [reference.md](reference.md).

Отдельная команда `freshness` показывает, до какой даты есть данные в каждом источнике:
у Вебмастера они отстают по-разному, а иногда застывают.

Логики «что хорошо, а что плохо» в скилле нет. Ответы кэшируются на диске до конца дня,
поэтому повторные вопросы не тратят лимиты.

## Установка

Нужен Python 3 и `requests`. При первом запуске агент увидит, что токена нет, и пойдёт в
[SETUP.md](SETUP.md). Там описано, как помочь вам получить OAuth-токен Яндекса и положить
его в `.env` рядом со скриптом.
