# Настройка yandex-wm-api — инструкция для ИИ-агента

Этот файл читает агент, который запустил `ywm.py` и получил ошибку про
`YANDEX_WEBMASTER_TOKEN` или 401. Проведи пользователя по шагам. Вход в Яндекс и
выдачу доступа делает он сам в браузере: не пытайся пройти эти шаги за него, а
проси выполнить их и прислать результат.

## 1. Зависимости

```
pip install -r requirements.txt
```

## 2. Есть ли уже токен

Спроси пользователя, нет ли у него OAuth-токена Яндекса с доступом к Вебмастеру
(например, от другого скрипта или от Метрики: один токен может покрывать оба сервиса).
Если есть — сразу к шагу 4.

## 3. Приложение и токен (пользователь, в браузере)

1. Открыть https://oauth.yandex.ru/client/new и войти в Яндекс-аккаунт, в котором сайты
   уже добавлены и подтверждены в Вебмастере.
2. Название — любое; платформа — **Веб-сервисы**; Redirect URI —
   `https://oauth.yandex.ru/verification_code`.
3. Доступ к данным: начать вводить «вебмастер» и выбрать **webmaster:hostinfo** — его
   хватает на всё чтение. **webmaster:verify** по документации нужен для добавления сайтов и
   подтверждения прав. Если запись (переобход, sitemap, сайты) вернёт 403, добавь его в
   приложение и получи токен заново.
4. Создать приложение и скопировать **ClientID**.
5. Открыть в браузере ссылку, подставив ClientID:
   ```
   https://oauth.yandex.ru/authorize?response_type=token&client_id=<ClientID>
   ```
   Разрешить доступ — на странице появится токен (`y0_...`). Пусть пользователь пришлёт его.

Токен живёт 6 месяцев. Когда скрипт снова вернёт 401, достаточно повторить пункт 5.

## 4. Заполнить .env

В папке скилла скопировать `.env.example` в `.env` и вписать токен:

```
YANDEX_WEBMASTER_TOKEN=y0_...
```

`YANDEX_WEBMASTER_USER_ID` можно не заполнять — скрипт узнает его сам. `.env` в
`.gitignore`, в публичный репозиторий не попадёт. Если у пользователя есть общий
файл с доступами, предложи записать токен и туда.

## 5. Проверка

```
python ywm.py hosts
```

Должен вывести user_id и список сайтов. Пустой список значит, что в этом аккаунте нет
подтверждённых сайтов: их добавляют в самом Вебмастере (или правами делится владелец),
скилл тут не поможет. Затем `python ywm.py freshness --host <сайт>` покажет, до каких
дат есть данные.
